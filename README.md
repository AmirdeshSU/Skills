# Skills

Claude skills for specifying web projects.

- `spec-before-build/` - six pre-build documents (PRD, TRD, app flow, design brief, backend schema, implementation plan) for a new site or app
- `spec-after-build/` - reverse-engineer the same six documents from an existing codebase, with Observed / Intended / Gaps
- `kits/` - the human-readable versions of both workflows
- `INDEX.md` - the other skills and plugins I use, with sources and pinned versions
